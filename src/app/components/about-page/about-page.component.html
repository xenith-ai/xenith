About

Create and interact with LLM-powered voice assistants in the browser with WebAssembly.

Xenith lets you build highly configurable voice assistants with custom wake words, voices, LLMs, and MCP connections—all running fully in-browser. Long term we plan to add more AI capabilities, including video and audio editing.

You’ll need a dedicated GPU and a browser with WebGPU support for the best experience.
